## Abstract

Queue 是 FIFO（First In First Out）的線性資料結構，從尾端（Rear）加入、從頭端（Front）取出，解決「先到的先處理」。
`enqueue`、`dequeue`、`peek` 都是 O(1)。
用陣列實作要做成 Circular Queue，用 Linked List 實作要同時記 head 和 tail。

---

## 操作

| 操作 | 說明 | 複雜度 |
|---|---|---|
| `enqueue` | 從 Rear 加入 | O(1) |
| `dequeue` | 從 Front 移除並回傳 | O(1) |
| `peek` / `front` | 只看 Front，不移除 | O(1) |

---

## 應用

- BFS：用 Queue 放待訪問的節點，確保一層一層走。
- Task Scheduling、Message Queue：照進來的順序處理。
- Producer-Consumer：生產者放進 Queue、消費者依序取出，常當作 Buffer。
- 列印佇列、請求佇列：照抵達順序排隊。

## 實作

### 陣列：Circular Queue

普通陣列 `dequeue` 之後前面的空間會浪費，不然就要把剩下的元素全部往前搬（O(n)）。
Circular Queue 用 `(index + 1) % capacity` 讓 Front、Rear 繞回陣列開頭，重複利用空間：

```java
class CircularQueue {
    private int[] data;
    private int front = 0, rear = 0, size = 0;

    public CircularQueue(int capacity) {
        data = new int[capacity];
    }

    public void enqueue(int value) {
        if (size == data.length) throw new RuntimeException("Queue is full");
        data[rear] = value;
        rear = (rear + 1) % data.length;
        size++;
    }

    public int dequeue() {
        if (size == 0) throw new RuntimeException("Queue is empty");
        int value = data[front];
        front = (front + 1) % data.length;
        size--;
        return value;
    }
}
```

### Linked List

`enqueue` 接在 `tail`，`dequeue` 從 `head` 拿，不用預設容量。

```java
class LinkedQueue {
    private static class Node {
        int value;
        Node next;
        Node(int value) { this.value = value; }
    }

    private Node head, tail;

    public void enqueue(int value) {
        Node node = new Node(value);
        if (tail == null) {
            head = tail = node;
        } else {
            tail.next = node;
            tail = node;
        }
    }

    public int dequeue() {
        if (head == null) throw new RuntimeException("Queue is empty");
        int value = head.value;
        head = head.next;
        if (head == null) tail = null;    // 拿到空了，tail 也要清掉
        return value;
    }
}
```

**`dequeue` 拿到空的時候要把 `tail` 也設成 `null`**，否則下一次 `enqueue` 會接在已經移除的節點後面。

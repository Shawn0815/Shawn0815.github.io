## Abstract

Stack 是 LIFO（Last In First Out）的線性資料結構，新增和刪除都在同一端（Top），解決「最後進來的要最先處理」。
`push`、`pop`、`peek` 都是 O(1)。
可以用陣列或 Linked List 實作，常見於 Function Call Stack、括號配對、DFS、Undo。

---

## 操作

| 操作 | 說明 | 複雜度 |
|---|---|---|
| `push` | 放到 Top | O(1) |
| `pop` | 移除並回傳 Top | O(1) |
| `peek` / `top` | 只看 Top，不移除 | O(1) |

---

## 應用

- Function Call Stack：函式呼叫的底層機制，遞迴能運作就是靠它。
- 括號配對、運算式求值：判斷 `()`、`{}`、`[]` 是否合法。
- DFS：用 Stack（或遞迴）放待訪問的節點。
- Undo / Redo：操作歷史放進 Stack，復原時從 Top 一個個拿出來。
- 瀏覽器上一頁：回上一頁就是 `pop`。

## 實作

### 陣列

用 `top` 記住 Top 的位置，`push` / `pop` 都在陣列尾端操作，不用搬動其他元素。

```java
class ArrayStack {
    private int[] data;
    private int top = -1;

    public ArrayStack(int capacity) {
        data = new int[capacity];
    }

    public void push(int value) {
        if (top == data.length - 1) throw new RuntimeException("Stack is full");
        data[++top] = value;
    }

    public int pop() {
        if (top == -1) throw new RuntimeException("Stack is empty");
        return data[top--];
    }

    public int peek() {
        if (top == -1) throw new RuntimeException("Stack is empty");
        return data[top];
    }
}
```

滿了要 resize（建更大的陣列再複製），好處是記憶體連續，cache locality 好。

### Linked List

`push` / `pop` 都在 head 操作，不用 resize。

```java
class LinkedStack {
    private static class Node {
        int value;
        Node next;
        Node(int value, Node next) {
            this.value = value;
            this.next = next;
        }
    }

    private Node head;

    public void push(int value) {
        head = new Node(value, head);
    }

    public int pop() {
        if (head == null) throw new RuntimeException("Stack is empty");
        int value = head.value;
        head = head.next;
        return value;
    }

    public int peek() {
        if (head == null) throw new RuntimeException("Stack is empty");
        return head.value;
    }
}
```

兩種實作都是 O(1)：陣列要預設容量、處理 resize；Linked List 每個節點多一個指標的記憶體。

## 跟 Queue 的差別

| | Stack | Queue |
|---|---|---|
| 順序 | LIFO | FIFO |
| 新增、刪除 | 同一端（Top） | 尾端加、頭端拿 |
| 適合 | 最近的先處理：Undo、DFS | 先到的先處理：任務排程、BFS |

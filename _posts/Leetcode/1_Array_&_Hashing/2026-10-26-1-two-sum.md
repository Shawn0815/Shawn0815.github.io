## Question

You are given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

**Example 1:**

> Input: nums = [2,7,11,15], target = 9
>
> Output: [0,1]
>
> Explanation: The sum of nums[0] and nums[1] is 2 + 7 = 9, which equals the target. Therefore, the indices [0, 1] are returned.

**Example 2:**

> Input: nums = [3,2,4], target = 6
>
> Output: [1,2]
>
> Explanation: The sum of nums[1] and nums[2] is 2 + 4 = 6, which equals the target. Therefore, the indices [1, 2] are returned.

**Example 3:**

> Input: nums = [3,3], target = 6
>
> Output: [0,1]
>
> Explanation: The sum of nums[0] and nums[1] is 3 + 3 = 6, which equals the target. Therefore, the indices [0, 1] are returned.

**Constraints:**

- 2 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- Only one valid answer exists.

**Follow-up**: Can you come up with an algorithm that is less than `O(n^2)` time complexity?

## 解法 1：Brute Force

### 辨識訊號

- 「two numbers such that they add up to target」：要找一對數字，最直覺的是把每一對都試一次。
- 「exactly one solution」：找到一對就可以直接回傳，不用找完。

### 關鍵提問

1. 最直覺的做法是什麼？
2. 每一對都試要試幾次？n 最大 10^4 夠不夠快？

### 思路

1. 固定第一個數字，往後找第二個數字。
2. 第二個數字從第一個的下一個開始，同一個元素不會用兩次。
3. 兩個加起來等於 target 就回傳兩個 index。

### Pseudo Code

```text
for i = 0 to len(nums) - 1:
    for j = i + 1 to len(nums) - 1:
        if nums[i] + nums[j] == target:
            return (i, j)

return an empty array or list
```

### 程式碼

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]

        return []
```

### 複雜度

- Time complexity: O(n²)
  - 每一對都試一次，約 n² / 2 對。
- Space complexity: O(1)
  - 只用到兩個 index。

### 瓶頸

- 每固定一個數字，都要往後走一遍才找得到夥伴，找一次是 O(n)。
- 夥伴是誰其實已經知道：`target - 自己`。如果能 O(1) 查到它在不在、在哪個 index，就不用往後走。

## 解法 2：HashMap（Two-pass）

### 辨識訊號

- 「two numbers such that they add up to target」：知道一個數字，夥伴就固定是 `target - 自己`。
- 要回傳 index：查到夥伴時，也要知道它的 index。
- Follow-up 要求低於 O(n²)：找夥伴不能再一個一個走。

### 關鍵提問

1. 找夥伴要 O(n)。能不能變成 O(1)？
2. 要查「某個數字在不在、在哪個 index」，用什麼資料結構？key、value 各放什麼？
3. 「may not use the same element twice」：查到的夥伴，會不會就是自己？

### 思路

1. 第一遍把每個數字放進 Map，key 是數字，value 是它的 index。
   重複的數字會留下最後一個 index，例：`[3, 3]` 變成 `{3: 1}`。
2. 第二遍對每個數字算出夥伴 `target - 自己`，查 Map，O(1)。
3. 查到了還要確認夥伴的 index 不是自己，才回傳兩個 index。
   例：`nums = [3, 2, 4]`、`target = 6`，3 的夥伴也是 3，查到的就是自己。

### Pseudo Code

```text
seen = new empty map (key = number, value = index)

for i = 0 to len(nums) - 1:
    seen[nums[i]] = i

for i = 0 to len(nums) - 1:
    complement = target - nums[i]

    if complement in seen and seen[complement] != i:
        return [i, seen[complement]]

return an empty list
```

### 程式碼

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}

        for i in range(len(nums)):
            seen[nums[i]] = i

        for i in range(len(nums)):
            complement = target - nums[i]

            if complement in seen and seen[complement] != i:
                return [i, seen[complement]]

        return []
```

### 複雜度

- Time complexity: O(n)
  - 走過 `nums` 兩次，每次查 Map、放進 Map 都是 O(1)。
- Space complexity: O(n)
  - Map 要存 n 個數字。

### 瓶頸

- 複雜度已經是 O(n)，但要走兩遍，還要另外判斷夥伴是不是自己。
- 如果一邊走一邊查，而且先查再放，Map 裡只會有前面的數字，就不會配到自己，也只要走一遍。

## 解法 3：HashMap（One-pass）

### 辨識訊號

- 「may not use the same element twice」：Map 裡只放前面的數字，就不會配到自己。
- 「exactly one solution」：答案的兩個數字一前一後，走到後面那個時，前面那個一定已經在 Map 裡。

### 關鍵提問

1. 一定要先把全部數字放進去，再查一遍嗎？查找和放進去能不能在同一個迴圈做？
2. 先查再放，還是先放再查？哪一種不會配到自己？

### 思路

1. 對每個數字，算出它的夥伴 `target - 自己`。
2. 用 Map 記錄看過的數字，key 是數字，value 是它的 index，查夥伴就是 O(1)。
3. 先查夥伴在不在 Map 裡：在就回傳兩個 index；不在才把自己放進去。
4. 先查再放，所以查到的一定是前面的其他元素，不會配到自己。

### Pseudo Code

```text
seen = new empty map (key = number, value = index)

for i = 0 to len(nums) - 1:
    complement = target - nums[i]

    if complement in seen:
        return [seen[complement], i]
    else:
        seen[nums[i]] = i

return an empty list
```

### 程式碼

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}

        for i in range(len(nums)):
            complement = target - nums[i]

            if complement in seen:
                return [seen[complement], i]
            else:
                seen[nums[i]] = i

        return []
```

### 複雜度

- Time complexity: O(n)
  - 走過 `nums` 一次，每次查 Map、放進 Map 都是 O(1)。
- Space complexity: O(n)
  - 最壞情況，Map 要存 n 個數字。

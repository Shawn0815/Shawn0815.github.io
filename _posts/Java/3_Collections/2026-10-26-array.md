## Abstract

Array 建立時就決定長度，之後不能增減；資料數量固定（例如 26 個字母的頻率）用 Array，數量不確定用 List。
常用操作都在 `Arrays` 工具類：`sort`、`fill`、`copyOf`、`toString`、`equals`。
容易錯的是：`=` 不會複製、`==` 不比內容、`int[]` 不能直接降冪排序或轉成 `List<Integer>`。

---

## 建立與存取

```java
int[] nums = new int[5];           // 指定長度，自動填預設值：int 0、boolean false、物件 null
int[] nums = {1, 2, 3};            // 直接給內容
int[] nums = new int[]{1, 2, 3};   // 完整寫法，回傳時常用：return new int[]{left, right};

int size = nums.length;            // 屬性，沒有括號；String 是 length()，List 是 size()
int first = nums[0];
int last = nums[nums.length - 1];
nums[i] = 10;
```

---

## 遍歷

```java
for (int i = 0; i < nums.length; i++) { }          // 需要 index 或要修改
for (int i = nums.length - 1; i >= 0; i--) { }     // 倒著走
for (int num : nums) { }                           // 只讀
```

**Enhanced for 改的是複本**：`for (int num : nums) num *= 2;` 跑完 `nums` 不會變，要改就用 index。

---

## Arrays 工具類

```java
Arrays.fill(nums, -1);                 // 全部填同一個值
Arrays.fill(nums, 1, 4, -1);           // [1, 4)
Arrays.sort(nums);                     // 由小到大，直接改原陣列
Arrays.sort(nums, 1, 4);               // 只排 [1, 4)
Arrays.toString(nums);                 // 印內容：[1, 2, 3]；直接印 nums 只會看到物件位址
Arrays.equals(nums1, nums2);           // 比內容；== 比的是不是同一個陣列
Arrays.binarySearch(nums, target);     // 陣列要先排序，找到回傳 >= 0 的 index
```

### 降冪排序

`int[]` 不能搭配 Comparator。
用 `Integer[]` 才能 `Arrays.sort(nums, Collections.reverseOrder())`；題目給 `int[]` 時，通常升冪排序後從尾端往前走。

## 複製

**`int[] copy = nums;` 不會建立新陣列**，兩個變數指向同一個，改一邊另一邊也變。

```java
int[] copy = nums.clone();
int[] copy = Arrays.copyOf(nums, nums.length);
int[] firstN = Arrays.copyOf(nums, n);
int[] part = Arrays.copyOfRange(nums, 1, 4);    // [1, 4)
```

## 常用片段

```java
// 找最大值（空陣列要先處理）
int max = nums[0];
for (int num : nums) max = Math.max(max, num);

// 交換
int temp = nums[left];
nums[left] = nums[right];
nums[right] = temp;

// 反轉：左右指標交換到相遇
```

Array 沒有 `contains()`，要自己走一遍找。

## 二維陣列

二維陣列是「外層陣列的每個元素又是一個陣列」，每一列可以不一樣長。

```java
int[][] grid = new int[3][4];
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};

int rows = grid.length;         // 列數
int cols = grid[0].length;      // 每列的長度
int v = grid[1][2];             // grid[1] 是 {4, 5, 6}，再取 [2] → 6
```

```java
for (int row = 0; row < rows; row++) {
    for (int col = 0; col < cols; col++) { }
}

for (int[] row : grid) {
    Arrays.fill(row, -1);       // Arrays.fill(grid, -1) 填不滿二維陣列，要一列一列填
}

Arrays.deepToString(grid);      // [[1, 2, 3], [4, 5, 6]]
Arrays.deepEquals(grid1, grid2);
```

**`grid.clone()` 只複製外層**，每一列還是共用。
真的要複製 Matrix 要一列一列 clone：

```java
int[][] copy = new int[rows][];
for (int i = 0; i < rows; i++) {
    copy[i] = grid[i].clone();
}
```

### 方向陣列與邊界

Grid 的 BFS / DFS 常用：

```java
int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};    // 上下左右；八方向再加四個斜角

for (int[] dir : directions) {
    int newRow = row + dir[0];
    int newCol = col + dir[1];
    if (newRow < 0 || newRow >= rows || newCol < 0 || newCol >= cols) continue;
}
```

## Java 怎麼表示 Pair

沒有通用的內建 Pair。
只有兩三個值、位置意思很清楚時用 `int[]`：`{row, col}`、`{start, end}`、`{node, distance}`。
欄位多或要清楚的名稱時，自己寫一個小 Class（例如 `Point` 有 `row`、`col`）。

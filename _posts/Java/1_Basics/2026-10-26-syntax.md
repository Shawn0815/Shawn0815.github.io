## Abstract

寫 LeetCode 時最常用到的 Java 語法：變數、條件、迴圈、提前結束，以及幾個常見的判空寫法。
很多題目一開始就用 Guard Clause 處理空輸入，條件簡單時可以用三元運算子。

## 變數

```java
int number = 10;
String text = "Hello";
boolean visited = false;
int a = 1, b = 2;     // 可以一行多個，但一行一個比較清楚
```

---

## 條件

```java
if (x > 0) {
} else if (x < 0) {
} else {
}
```

```java
switch (direction) {
    case 0:
        break;
    default:
        break;
}

// Java 14 以後
switch (direction) {
    case 0 -> System.out.println("Up");
    case 1 -> System.out.println("Down");
    default -> System.out.println("Unknown");
}
```

舊寫法的 `case` **忘了 `break` 會一路往下執行**，新的 `->` 寫法沒有這個問題。

三元運算子適合簡單判斷，不要巢狀：

```java
int max = a > b ? a : b;
return answer == Integer.MAX_VALUE ? -1 : answer;
```

## 迴圈

```java
for (int i = 0; i < n; i++) { }          // 一般
for (int i = n - 1; i >= 0; i--) { }     // 倒著走
for (int i = 0; i < n; i += 2) { }       // 跳步

for (int num : nums) { }                 // Enhanced for：拿不到 index，也不能直接改集合內容

while (!queue.isEmpty()) { }             // BFS、Two Pointers、Binary Search 常用
```

`break` 結束整個迴圈，`continue` 跳過這一輪：

```java
for (int num : nums) {
    if (num < 0) continue;
    if (num == target) break;
}
```

## 提前 return（Guard Clause）

```java
if (head == null) {
    return null;
}
```

常見的判空：

```java
if (nums == null || nums.length == 0) return;    // 陣列
if (text == null || text.isEmpty()) return;      // 字串
if (list.isEmpty()) { }                          // List、Map、Set 都有 isEmpty()
```

`||` 會短路：`nums == null` 成立就不會再算 `nums.length`，所以 **`null` 檢查要寫在前面**。
